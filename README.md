Language Detection from Text

Overview

This project detects the language of user-entered text using Python and the "langdetect" library in Google Colab. It supports multiple languages such as English, Telugu, Hindi, Tamil, French, Spanish, German, Japanese, and Korean.

Features

- Detects language from text input
- Displays language code and language name
- Runs in a single Google Colab cell
- Beginner-friendly project

Technology Used

- Python
- Google Colab
- langdetect library

How to Run

1. Open Google Colab.
2. Copy and run the code.
3. Enter any text.
4. View the detected language.

Example

Input: "Hello, how are you?"

Output: "Detected Language: English"
